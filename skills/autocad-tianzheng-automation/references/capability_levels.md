# 能力等级

- `IMPLEMENTED`：代码和测试已覆盖声明范围。
- `IMPLEMENTED_BASELINE`：Mock/基础合同可用，但不代表真实 CAD。
- `PARTIALLY_IMPLEMENTED`：只有部分链路或证据。
- `INTERFACE_ONLY`：仅接口，不可宣称实现。
- `DISABLED_CONTRACT_ONLY`：合同存在，明确禁止执行。
- `NOT_IMPLEMENTED`：未实现。
- `UNSAFE`：已知不安全，拒绝。

验证维度必须独立：`geometry_verified`、`object_type_verified`、`properties_verified`、`display_environment_verified`、`native_topology_verified`、`engineering_semantic_completeness_verified`、`visual_review_verified`。
